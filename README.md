# 🕷️ ESP32 Web Shooter

A gesture controlled web shooter prototype built using an ESP32 DevKit and MPU6050 motion sensor. The system detects specific hand movements and triggers a buzzer as feedback, creating a wearable, motion controlled interaction system inspired by fictional web shooters.

## 🚀 Features

- Gesture based motion detection
- MPU6050 accelerometer and gyroscope
- ESP32 DevKit based control system
- Buzzer for audio feedback
- Compact prototype design
- Arduino IDE based firmware
- Python assisted development and testing

## 🧰 Hardware

- ESP32 DevKit
- MPU6050
- Buzzer
- Jumper wires
- Breadboard
- USB cable / power source

## 💻 Software

- Arduino IDE
- C/C++ for ESP32 firmware
- Python for development and testing

## ⚙️ How It Works

The MPU6050 continuously measures the motion and orientation of the device. The ESP32 processes the sensor data and identifies predefined gestures. When the required gesture is detected, the ESP32 activates the buzzer to provide immediate feedback.
